# K3-05. Разбор лога pipeline

В Student CI временно изменил путь сборки с `lab/Dockerfile` на `lab/MissingDockerfile`. Тесты не менял.

## Неуспешный запуск

- [Запуск с ошибкой сборки](https://github.com/VonOfficial/DevOps-course/actions/runs/43473347211).
- Событие: push.
- SHA: `cbe7656085d7d40a9919741427bdaf405bd597bd`.
- test: success.
- build: failure.

Первое содержательное сообщение об ошибке:

```text
ERROR: failed to build: failed to solve: failed to read dockerfile: open MissingDockerfile: no such file or directory
```

Причина: в команде указан несуществующий файл `lab/MissingDockerfile`. Docker не смог прочитать инструкции сборки и завершил работу с кодом 1. Правильный файл находится по пути `lab/Dockerfile`.

## Исправление

Восстановил правильный путь. Итоговая команда:

```text
docker build -f lab/Dockerfile -t devops-student:${{ github.sha }} lab
```

- [Исправленный запуск](https://github.com/VonOfficial/DevOps-course/actions/runs/43474479956).
- Событие: push.
- SHA: `5b4c77fe1759723da5054b250a95a35ddb26b93b`.
- test: success.
- build: success.

После исправления пути тесты и сборка успешно выполнились в одном запуске.

## Ответ на вопрос

Ошибка теста означает несовпадение фактического результата с ожидаемым. Отсутствие Dockerfile — ошибка настройки команды сборки. В этом случае тесты приложения проходят, но Docker не может собрать образ.

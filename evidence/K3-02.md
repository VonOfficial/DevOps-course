## Выполненные шаги

- `actions/checkout` получает файлы проверяемой версии проекта.

- `python --version` выводит установленную версию Python.

Вывод последней команды: `Python 3.13.18`.

Job - отдельное задание, которое выполняется на runner. Step — отдельный шаг внутри задания. Шаги выполняются последовательно.

## Ответ на вопрос

Успешный запуск `python --version` подтверждает только доступность Python и его версию. Эта команда не запускает приложение и не проверяет его работу. Для этого нужно добавить автоматические тесты.

# K3-04. Сборка после тестов

В Student CI добавил отдельный job `build` с `runs-on: ubuntu-latest` и зависимостью `needs: test`.

Внутри build используется отдельный checkout с тем же SHA Action, что и в шаблоне курса. Он получает исходники в среду задания сборки.

Команда сборки:

```text
docker build -f lab/Dockerfile -t devops-student:${{ github.sha }} lab
```

`${{ github.sha }}` задает тег образа по SHA проверяемой версии.

## Проверка зависимости

После добавления build временно изменил ожидаемый статус в `test_create_request` с 201 на 200.

- [Запуск с ошибкой теста](https://github.com/VonOfficial/DevOps-course/actions/runs/43471848390).
- Событие: push.
- SHA: `2320c2568175f7bbdafc6b1e7895d11d63b3363f`.
- test: failure.
- build: skipped.

Тест завершился с ошибкой, поэтому зависимое задание build было пропущено.

## Исправленный запуск

Вернул ожидаемый статус 201 и сохранил исправление новым коммитом.

- [Успешный запуск](https://github.com/VonOfficial/DevOps-course/actions/runs/43472393637).
- Событие: push.
- SHA: `2d28fffed869279885e8ede359bf014c354b4902`.
- test: success.
- build: success.

В одном запуске успешно выполнены тесты и сборка образа. В логе сборки указан образ:

`devops-student:2d28fffed869279885e8ede359bf014c354b4902`

## Ответ на вопрос

Образ хранится локально на runner. В этой работе он не отправляется в registry. После удаления runner образ будет потерян вместе с его окружением.
